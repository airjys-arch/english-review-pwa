- Android 전용 프로젝트
- 기초영어 Day1~15 + 인턴 영어회화 Day1~10 통합 콘텐츠
- 빈칸 채우기 / 말하기 / 3초 즉답 / 영어 듣기 / 음성인식 / 오답·진도 저장
- 앱 데이터는 기기 내부 WebView localStorage에 저장

APK 만들기
1. Android Studio에서 이 폴더를 엽니다.
2. Gradle Sync를 완료합니다.
3. Build > Build App Bundle(s) / APK(s) > Build APK(s)를 선택합니다.
4. 생성된 app-debug.apk를 안드로이드폰에 설치합니다.

주의
